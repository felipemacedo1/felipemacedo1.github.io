# ADR 001 — Static engineering portfolio

Accepted 2026-09-23. Astro generates semantic HTML at build time. TypeScript enhances navigation and loads one Three.js scene lazily. No React hydration, backend, adapter, paid hosting, runtime API, or client credentials. All production files live in dist/ on GitHub Pages; public/CNAME preserves felipemacedo.me.

PT-BR / and EN /en/ use versioned content. Locale types and dictionaries allow a future ES translation without runtime translation. Native anchors and scrolling remain intact. The scene is explanatory and optional: original SVG diagrams survive JavaScript/GPU failure.

Three.js 0.186.0 evaluated against official WebGPURenderer documentation. Start with WebGL2: point/line drawings do not justify WebGPU renderer complexity and larger payload. Browsers lacking WebGL2 keep SVG. WebGPU can be adopted only with measured benefit and equivalent WebGL2/failure coverage.

Asset research: Three.js (MIT), Lucide (ISC), Fontsource IBM Plex Sans/Mono (OFL). Choose original procedural geometry and small inline icons over downloaded shaders, stock loops, models or videos. No reference-site code/assets copied. Existing growthfolio portrait inspected; use a small natural portrait only in journey. Credly badge marks remain issuer-owned and link to their official assertions.

Previous site at 3e0014b preserved in archive/pre-engineering-redesign. Its duplicate enterprise modules, fake filesystem/CV entries, contribution collectors, mobile BIOS and cache worker are retired. A small optional legacy command interface reuses current central content; old implementation remains in Git, not the payload.

Pages API currently reports build_type=legacy despite the Actions workflow. Change Settings > Pages > Source to GitHub Actions when merging this migration. The PR workflow validates without publishing. No automatic merge.
